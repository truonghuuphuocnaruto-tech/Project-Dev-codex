# Project-Dev-codex: Vụ Án "Bản Giao Hưởng Đoạt Mệnh" 🕵️‍♂️🔍
> **Web Game Trinh Thám Điều Tra Án Mạng (VibeCode Hackathon Interactive Demo)**

Dự án game trinh thám suy luận vụ án tương tác xây dựng bằng **React + Vite + TypeScript + Tailwind CSS** và **Web Audio API**.

## 🌟 Tính Năng Trọng Tâm
1. **Case Briefing (Hồ Sơ Mật):** Tiếp nhận hồ sơ vụ án Nhạc trưởng Hoàng Long bị đầu độc lúc 22:15.
2. **Crime Scene Investigation:** Hiện trường tương tác point-and-click với 6 hotspot thu thập vật chứng.
3. **Interrogation Room:** Thẩm vấn 3 nghi phạm (Vợ, Trợ lý, Đối thủ) kèm tính năng **"Trưng Bằng Chứng" (Present Evidence)** bẻ gãy lời khai giả.
4. **Detective Pinboard:** Bảng ghim Polaroid kéo thả tự do, **nối dây chỉ đỏ (Red String SVG)** liên kết manh mối.
5. **Verdict & Case Resolution:** Tuyên án, chấm điểm suy luận Rank S/A/B và pháo giấy ăn mừng `canvas-confetti`.
6. **⚡ Judge Fast-Track (60s):** Nút tắt mở khóa toàn bộ tiến trình để thuyết trình nhanh trước Ban Giám Khảo.

## 🚀 Khởi Chạy
```bash
npm install
npm run dev
```
